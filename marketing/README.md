# ForPrint Marketing Workspace

**Status:** canonical marketing workspace root

`marketing/` is the project-owned workspace for long-lived promotion,
measurement, research, campaigns, experiments, reports, and evidence.

SEO/organic search is one subdomain. It is not the umbrella name for Google
Ads, Analytics, Search Console, Business Profile, hosting analytics, or future
marketing integrations.

Control-plane configuration lives in `config/marketing/`.
Python automation lives in `scripts/marketing/`.
Current documentation lives in `docs/marketing/`.
ADRs remain centralized in `docs/decisions/`.
Historical snapshots remain under `docs/status/snapshots/`.

Stable areas: `programs/`, `campaigns/`, `research/`, `organic-search/`,
`local-presence/`, `measurement/`, `data/`, `reports/`, `experiments/`,
and `archive/`.
