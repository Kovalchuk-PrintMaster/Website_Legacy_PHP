# Marketing campaigns

Campaigns use stable project IDs. Do not move campaigns between `active/`,
`paused/`, or `completed/` directories. Change lifecycle state in the registry.

Execution evidence must remain attributable to campaign, provider/account,
operation plan, and execution time.
