**Дата:** 2026-08-12
**Статус:** accepted

## Канонічний корінь

```text
README.md
Makefile
base/
config/
coordination/
database_dumps/
docs/
marketing/
scripts/
```

`marketing/` є канонічним workspace для promotion, search, advertising,
measurement, local presence, research, reports та experiments.

`seo/` більше не є канонічним top-level namespace. Контрольована migration завершена; `seo/`, `docs/seo/` і `scripts/seo/` не є current workspace. Історичний контекст зберігається у Git history та explicit historical records.

## Приховані локальні каталоги

```text
.git/
.venv_website/
.runtime/
```

`.venv_website/` залишається через чинні Makefile, документацію та
inspection-контракти. Її перенесення потребує окремого рішення.

## Конфігураційні namespaces

```text
config/env/                    tracked environment examples
config/deployment/             deployment ownership/contracts
config/marketing/              marketing machine-readable control plane
config/python/                 Python tooling dependency/configuration manifests
.runtime/env/                  ignored local runtime fallback
/etc/forprint/                 active systemd environment
```

Python dependency manifests не розміщуються окремим `requirements/` у корені.
Поточний marketing manifest:

```text
config/python/requirements/marketing.txt
```

Кореневий `pyproject.toml` не вводиться лише для internal scripts. Якщо Python
tooling стане окремим cohesive Python project/package, його project root і
packaging metadata визначаються окремим архітектурним рішенням.

## Робочі та tooling namespaces

```text
marketing/                     marketing workspace/evidence
scripts/marketing/             Python marketing automation
scripts/inspection/            reusable read-only audits and validators
scripts/maintenance/           explicit controlled mutation
tmp/                           temporary operator/generated workspace
docs/marketing/                current marketing architecture/policies/plans/reference
coordination/reports/          historical implementation evidence
```

Нові cross-channel marketing contracts, automation та workspace objects створюються тільки під `marketing/`, `config/marketing/`, `scripts/marketing/` і `docs/marketing/`.

Переміщення legacy SEO material виконується лише після inventory/classification
і explicit `git mv`.

## Root hygiene

`README.md` і `Makefile` залишаються в корені.

У корені заборонені generated bytecode, package/documentation archives,
one-off migration/audit helpers, окремий `requirements/` namespace, secrets і
credential material.

Root `tmp.py` і `tmp.php`, а також `tmp/`, є дозволеним локальним ignored
temporary state і не є canonical repository content.

## Runtime boundary

Systemd продовжує використовувати:

```text
/etc/forprint/website-preview.env
```

`.runtime/` є ignored project-local fallback/runtime state.

Production/runtime secrets не стають частиною Git-tracked `config/`.
