# Політика кореня репозиторію та локального runtime v0.1

**ID:** `FP-WEB-ARCH-ROOT-001`
**Дата:** 2026-07-29
**Статус:** superseded
**Superseded by:** `docs/architecture/repository_root_and_runtime_layout_v0_2.md`

## Канонічний корінь

```text
README.md
Makefile
base/
config/
coordination/
database_dumps/
docs/
scripts/
seo/
tmp/
```

Приховані локальні каталоги:

```text
.git/
.venv_website/
.runtime/
```

`.venv_website/` залишається через чинні Makefile, документацію та
inspection-контракти. Її перенесення потребує окремого рішення.

## Розміщення

```text
docs/documentation/install/    installation notes
docs/documentation/packages/   documentation packages and checksums
config/env/                    tracked environment examples
.runtime/env/                  ignored local runtime fallback
/etc/forprint/                 active systemd environment
tmp/                           temporary operator/generated workspace
scripts/inspection/            reusable audits and validators
```

`README.md` і `Makefile` залишаються в корені. Секрети, generated bytecode
та package archives у корені заборонені. Root `tmp.py` і `tmp.php`, а також
`tmp/`, є дозволеним локальним ignored temporary state і не є canonical
repository content.
