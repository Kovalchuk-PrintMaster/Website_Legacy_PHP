# First 30 days: visibility and promotion plan v0.1

**ID:** `FP-WEB-SEO-PLAN-30D-001`
**Date:** 2026-07-29
**Status:** active plan

## Days 1–3

- verify Search Console by DNS;
- inspect and request indexing for a small representative URL set;
- record HTTPS, forms and current-page baseline;
- do not submit the legacy sitemap;
- open the exact Google Ads account/payments task and record its status.

## Days 4–10

Local work only:

- correct canonical-origin ownership;
- correct sitemap generation;
- add the robots sitemap directive;
- review `lang`, titles, descriptions and route indexation;
- classify home, category, product/service, cart, search and admin surfaces;
- create targeted inspection scripts;
- produce a local accepted Git checkpoint.

## Days 11–17

- prepare a controlled release from the accepted commit;
- deploy approved application files as a mirror update;
- run production HTTPS, canonical, sitemap, robots and form smoke tests;
- submit the corrected HTTPS sitemap;
- inspect representative deployed URLs.

## Days 18–24

- resolve the Google Ads account issue;
- prepare a narrow campaign and direct HTTPS final URLs;
- review ad claims and destination quality;
- enable only the approved pilot;
- monitor daily without changing production code.

## Days 25–30

- compare forecast versus actual observations;
- review Search Console discovery and indexation;
- review campaign search terms and spend;
- compare accepted inquiries by time window;
- prepare the next local content/interface backlog;
- decide: pause, continue unchanged, or expand one controlled dimension.

## Deferred beyond this plan

- broad multilingual rollout;
- extensive structured data;
- product/database synchronization;
- broad content generation;
- aggressive link acquisition;
- HSTS;
- broad paid-media expansion.
